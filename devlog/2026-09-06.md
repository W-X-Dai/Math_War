# 2026-09-06 — 慢速彈頭生命週期修正（0.8.2）

## 問題與修正

- 確認 `5`／`1.5` 秒是刻意設定的水平／落下彈頭速度，推翻 0.8.1 將其視為誤植的判斷；新增精確設定測試，避免後續再次加速。
- 水平彈頭改為發射後沿路線獨立前進，不再由發射時的敵人擁有。以連續掃掠碰撞計算同一幀內的相遇點，並在每次命中後重新評估其餘彈頭；前方敵人先被消去時，後續彈頭不會憑空消失，而會命中同路下一隻活敵人。
- 歸零敵卡立即離場，不再等待指向它的彈頭。當同路已無敵人，水平彈頭仍會保持原 ID 飛到戰場右邊界之外才清除；波次也會等待這些彈頭離場後再換段。
- 由上方落下的單體武器維持施放時的目標鎖定；原目標提前消失時只會落空，不會改打相同位置的新敵人。漏進基地的敵人同樣立即移除。
- 版本提升為 `0.8.2`。沒有存檔、關卡 seed、公開介面或部署遷移影響。

## 驗證

- `npm test`：完整測試通過；涵蓋慢速設定、同路雙敵續撞、同幀多彈重算、2× 速度掃掠碰撞、歸零字卡立即移除、最後一怪後彈頭完整離場、落下武器不轉移目標，以及既有數學與關卡行為。
- `npm run build`：正式版建置通過並更新 `dist/`。
- Headless Chrome/CDP（`1440×900`，一般與減少動態效果模式）：逐幀確認第一隻敵人歸零後 DOM 立即移除，後續水平彈頭保持相同 ID 向右前進並命中第二隻敵人；最後一怪消失後，孤立彈頭仍飛出右邊界才清除。頁面無 console error、framework overlay 或空白畫面。
- Browser 外掛、in-app browser 與專案 Playwright 均不可用，因此沿用 repository 既有的本機 Headless Chrome/CDP 驗證方式。

# 2026-09-06 — 參數捲軸與跨路線單體施放（0.10.0）

## 功能與設計

- 把 `P(x)−k`、定積分、`f(k)`、`xD+kI` 與 `D²+kI` 五種參數武器從占用路線的砲台改為一次性捲軸；`D` 與 `D²` 維持可重複攻擊、可擋路的通用砲台。
- 組裝常數後，玩家點擊空白捲軸即可刻寫參數；定積分依序刻寫下界與上界。完成後再點捲軸與任意路線的單一敵人，便由上方落下並在命中時套用算子。完成的捲軸不能覆寫，取消、無效目標、施放前運算失敗或算力不足不會消耗；通過檢查並發射後若目標提前消失，捲軸仍依既有落下武器規則消耗並落空。
- 關卡生成器改按敵人本體、等式護盾與分裂子代的實際使用次數供應參數捲軸及精確公式／`k`；可重複攻擊的砲台仍按路線去重。對數敵人的正式反制改為 `f(1)`，避免 `D → Euler(1)` 受慢速水平彈頭時序干擾。
- 保留既有 operator ID；`installAssembly` 引擎入口名稱仍可使用，但目的地改為軍械 queue 的捲軸 ID。沒有 localStorage、進度 JSON 或後端資料遷移。參數武器的種類由砲台改為單體目標武器，屬向後相容的玩法能力調整，版本提升為 `0.10.0`。

## 驗證

- `npm test`：10 個測試檔全部通過；引擎、生成器、平衡、設定與彈頭測試涵蓋單／雙參數刻寫、不可覆寫、跨正式段保存、跨路線選敵、無效施放不消耗、命中後消耗，以及本體／護盾／分裂子代的逐張保障供應。
- `npm run build`：正式版建置通過並更新 `dist/`。
- Headless Chrome/CDP（`1440×900`）：從第三關整備實際組出 `1`、刻寫 `xD+1I`、開波並對 `x⁻¹` 施放；已刻寫牌顯示正確，發射時消耗一張牌與 `Σ40`，落下彈頭鎖定原敵人並將其消去，全程沒有建立 Euler 塔。頁面標題與內容正常，沒有水平溢位、console error、資源失敗或 framework overlay。
