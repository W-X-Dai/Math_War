# 2026-09-06 — 彈頭命中同步修正（0.8.1）

## 問題與修正

- 集中遊戲設定時，水平與落下彈頭的飛行時間從原本的 `0.52`／`0.56` 秒誤寫為 `5`／`1.5` 秒。恢復原始次秒級時序，避免已鎖定的移動敵人在彈頭抵達前不合理地漏進基地，並加入精確設定與基地邊界回歸測試。
- 彈頭現在會逐步套用目標公式卡的群聚水平／垂直位移；目標消失後，該枚彈頭會在剩餘動畫期間沿用最後一次位置，避免跳回未錯位的模擬座標。快取只保留仍存在的彈頭，不會在無限模式持續累積。
- 移除依彈頭自身寬度計算的敵卡邊界錨點，改以彈頭中心對準目標；命中光圈會在同幀敵人移動後繼續貼住未死亡的目標。
- 版本提升為 `0.8.1`。沒有存檔、關卡 seed、公開介面或部署遷移影響。

## 驗證

- `npm test`：9 個測試檔全部通過，新增彈頭時序、近基地移動目標、命中光圈跟隨、群聚位移、邊界座標及快取清理覆蓋。
- `npm run build`：正式版建置通過並更新 `dist/`。
- Headless Chrome/CDP（`1440×900`）：實際確認 `x²` 在 `0.52` 秒飛行期間不變，命中後成為 `2x`；三隻同路群聚時，彈頭命中點位於目標公式卡內，目標與命中效果座標一致，基地未受傷，且沒有 console error、framework overlay 或空白頁。
- Browser 外掛、in-app browser 與專案 Playwright 均不可用，因此沿用 repository 既有的本機 Headless Chrome/CDP 驗證方式。
