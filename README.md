# 微分防線

「微分防線」是一款以微積分為戰鬥規則的 PC 網頁塔防遊戲。敵人不是用固定血量表示，而是一條會持續向「證明核心」前進的函數；玩家要部署微分、積分、極限等算子，在敵人抵達基地前把函數化成 `0`。

遊戲採 PC 桌面設計，適合使用滑鼠搭配鍵盤遊玩；較窄的桌面視窗會避免內容溢出，但目前沒有另外設計手機介面。所有內容都在瀏覽器本機執行，沒有後端服務或帳號系統。

## 執行方式

需求：Node.js 18 與 npm。專案使用 Vue 3.5.40、Vite 6.4.3 與原生 ES modules；套件版本已精確鎖定，以維持目前 Node 18 開發環境的相容性。

```bash
npm install
npm run dev
```

開發伺服器預設位於 <http://127.0.0.1:5173/>。

開發模式已安裝 Vue DevTools。可按 `Alt + Shift + D` 切換頁內工具列，或開啟 <http://127.0.0.1:5173/__devtools__/> 使用獨立介面；正式版建置不會帶入 DevTools。

執行數學核心與遊戲引擎測試：

```bash
npm test
```

建立正式版並在本機預覽：

```bash
npm run build
npm run preview
```

預覽伺服器預設位於 <http://127.0.0.1:4173/>；正式版輸出至 `dist/`。建置檔使用相對資源路徑，因此既可用 `npm run preview`，也可讓 Live Server 從任意父目錄開啟 `dist/index.html`，不會再因網站掛載路徑不同而找不到 CSS 或 JavaScript。

## GitHub Pages 部署

專案透過 `.github/workflows/deploy-pages.yml` 在每次推送 `main` 時執行 `npm ci`、建立正式版並將 `dist/` 上傳至 GitHub Pages。首次使用時，在 repository 的 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**；不需也無法在 branch 模式中指定 `/dist`。

正式版使用可攜式相對路徑，部署到 <https://w-x-dai.github.io/Math_War/>、repository 更名、根網域或自訂網域時都不需要再修改 Vite `base`。

## 核心玩法

每次新遊戲會產生一組 seed；同一 seed 會完整重現六個章節的敵人、路線與補給。六章依序是多項式、常數、多項高階、多變數、對數分式與三角指數，通關後進入沒有勝利終點的「無限證明」。結算可選擇以同 seed 重玩，或產生新 seed 開局。

地圖會隨章節由 `4×7` 擴張至 `6×12`，無限章則為 `7×12`，約六成欄位可部署砲台。每個有限章與首次進入無限章會清空戰場及三條 queue，並依章節重設算力與固定起始補給；完成有限章時證明核心會修復 `100 HP`。玩家已組裝但尚未使用的常數會跨章保留；無限章內的砲台、算力與 queues 也會跨輪保留。

每個有限章都依序經過「新敵人介紹 → 新軍械介紹 → 固定教學波 → seeded 隨機正式波」。介紹會說明新函數族與變異的特徵、危險和解題線索；教學波則提供固定敵人、固定軍械，以及標有「教學預置」且不可拆除的示範塔，讓玩家先看懂互動再接受正式挑戰。教學波是獨立沙盒：不提供提早開始獎勵，失敗會直接重試，通過後會還原教學前的基地生命、累計消去數、最高連鎖、常數庫及 RNG，再用該章標準經濟進入正式波。無限章不插入教學波。

正式的有限章有 30 秒整備；無限第 `r` 輪為 `max(10, 32−2r)` 秒。玩家可以提早開始，依畫面剩餘整秒取得每秒 `Σ5`、最多 `Σ150` 的獎勵。整備摘要只揭露敵人總數、函數族、變異數與危險度，不會洩漏確切公式、路線或出場時間。

進入每個有限章時，畫面會先逐張介紹該章的新敵人，再介紹剛解鎖的軍械、部署方式與適用函數。閱讀介紹期間，整備倒數與三條 queue 都會暫停，讀完才開始固定教學波的整備。

戰鬥中每五秒會補充算力，消去敵人也會取得獎勵。敵人由右向左前進，會持續攻擊擋路砲台；抵達證明核心時只依當下係數造成一次傷害，隨即離場且不提供消去獎勵。暫停或切換瀏覽器分頁時，戰鬥、整備與補牌計時都會停住。

敵人直接以自己的式子作為外觀，不再另外覆蓋角色圖。本體式歸零才算被消滅；傷害取本體式所有項之「係數絕對值總和」，攻擊結算時向上取整且至少為 1。敵人身上不會提示還需要幾次微分，玩家必須自行判斷；同一路的敵式太靠近時會做小幅錯位，但模擬座標不會改變。例如 `x⁵` 遭到微分砲連續命中時：

```text
x⁵ → 5x⁴ → 20x³ → 60x² → 120x → 120 → 0
```

因此它要被微分六次才會死亡；常數 `120` 仍不是零，若此時攻擊，能造成 120 傷害。這也代表算子不一定只會削弱敵人：錯誤的微分、平移或極限可能先放大係數，甚至讓敵人暴走。

函數敵人包含整數正負次方、雙變數、`aeᵇˣ`、`a sin(bx)`、`a cos(bx)` 與 `axᵖ ln|x|`。可取得的軍械如下：

| 軍械 | 效果 |
| --- | --- |
| `D` 微分砲 | 對同一路目標持續施作 `d/dx`。 |
| `P(x)−[ ]` 參數平移砲 | 裝入工坊常數後持續減去該常數。 |
| `D²` 高階砲 | 每次命中連做兩次微分。 |
| 定積分塔 | 裝入下界與上界，把目標化成定積分常數；跨越 `x=0` 奇點時會停火並說明原因。 |
| `f([ ])` 代入塔 | 把敵式代入 `x=k`；若 `k` 是根可直接歸零，遇到奇點則停火。 |
| `xD＋[ ]I` Euler 塔 | 處理多項式、分式與對數；`k=n` 可消去 `x⁻ⁿ`。 |
| `D²＋[ ]I` 共振塔 | 以 `b²` 消去三角式，或以 `−b²` 消去 `eᵇˣ`。 |
| `∫ + C` 不定積分 | 單體一次性武器，積分常數從 `−10、−5、0、5、10` 隨機抽取。 |
| `x ↦ −x` 輸入反射 | 單體一次性武器，可把成長指數轉成衰減指數。 |
| `lim x→∞` 無窮極限 | 負次方會歸零；三角式極限不存在、其他式若發散則會讓敵人暴走。 |
| `∂/∂x` 全場偏微分 | 昂貴的全場一次性武器，每輪限用一次，施放前會預覽目前最外層式子的結果。 |

每次成功攻擊都會以實際施作的算子作為公式彈頭：砲台沿路線射出 `d/dx`、`d²/dx²`、`f(k)` 等水平子彈；單體武器由上方落向所選敵人，全場偏微分則對每隻存活敵人各落下一枚 `∂/∂x`。公式中的正負號、`π`、上下界與塔內參數都會反映當次攻擊。彈頭飛行期間不會預先改寫敵式，也不再繪製連接射線；只有彈頭真正命中時，才會依敵人當下最外層的式子結算轉換、破盾、發散、消去與分裂。

軍械不是無限購買：容量八張的軍械 queue 每八秒補一張，從當前已解鎖軍械依章節與下一輪需求加權抽取。成功放塔或施放武器才會同時消耗軍械牌與算力；取消、目標無效或算力不足均不消耗。數字鍵 `1`～`8` 選擇對應 queue 槽位。

敵人可能帶有「快進」、「等式護盾」或「分裂」變異。快進提升速度與獎勵；等式護盾會把本體式的獨立複本做成一張卡，直接覆蓋在本體上。所有算子都會先改寫這張護盾式，只有把它化成 `0` 才會揭露本體，而且同一發攻擊不會穿透到本體；破盾本身不算消去，也不提供獎勵。分裂敵人歸零後會拆成兩隻不可再次分裂的單項敵人。無限第八輪起可能同時出現兩種變異，但護盾與分裂不會共存。

## 公式工坊：任選公式與 k

工坊有兩條會隨時間補充的佇列：公式與「上帝常數 `k`」。不必只能使用隊首；可以直接點選任意一張公式卡與任意一個 `k`，畫面會即時預覽組合結果。例如選取 `2k` 與 `k = 7`，便會得到常數 `14`。

操作流程：

1. 在公式佇列點選任意公式，例如 `k`、`k + 10`、`2k`、`k²` 或 `−k²`。
2. 在常數佇列點選任意 `k`。
3. 確認預覽後按「組裝此常數」；被選的公式與 `k` 會各消耗一張，結果存入最多五格的常數庫。
4. 任選一個已存常數，再點擊相容的空槽塔：`P(x)−[ ]`、`f([ ])`、`xD＋[ ]I`、`D²＋[ ]I`，或依序安裝定積分塔的下界與上界。成功安裝才會消耗該常數。

兩條佇列容量皆為十張；公式約每六秒補一張，`k` 約每 7.5 秒補一張。`k` 可抽到 `π` 與 `−π`；三角章固定提供 `k、2k、k²、−k²` 及 `0、1、2、π`。佇列滿時補牌倒數會停在原位，直到騰出空間。常數庫滿五格時不能再組裝，但不會誤扣材料；未使用的庫存跨有限章及首次進入無限章保留。

## 丟棄資源與砲台

軍械牌、公式卡、`k` 卡、已組裝常數和場上的砲台都能拖曳。任意一張都可直接拖到工坊下方的垃圾桶丟棄，不受 queue 位置限制；拆除砲台不會退還算力。畫面不提供額外的丟棄按鈕。

鍵盤玩家可以先用 `Tab` 聚焦軍械、公式、`k`、已組裝常數或砲台，再按 `Delete` 執行相同操作。

## 鍵盤操作

| 按鍵 | 操作 |
| --- | --- |
| `1`～`8` | 選擇軍械 queue 對應槽位。 |
| `Esc` | 取消目前的砲台放置、單體目標或確認視窗。 |
| `Space` | 暫停或繼續演算。 |
| `Tab` / `Shift + Tab` | 在可操作元件間向前／向後移動焦點。 |
| `Enter` | 啟用目前聚焦的按鈕、格子、敵人或砲台。 |
| `Delete` | 丟棄目前聚焦的軍械、公式、`k` 卡、已組裝常數或砲台。 |

切換到其他瀏覽器分頁時，進行中的戰鬥也會自動暫停。

## 專案架構

```text
.
├── index.html                 # Vite 入口與頁面 metadata
├── public/assets/             # 戰場、砲台、敵人與算子圖像
├── src/
│   ├── domain/expression.js   # 式子正規化、微積分、極限、傷害計算
│   ├── game/content.js        # 章節、棋盤、軍械與工坊卡片資料
│   ├── game/level-generator.js # Seeded 有限／無限波次與摘要生成器
│   ├── game/tutorial-content.js # 敵人圖鑑與六章固定教學波內容
│   ├── game/engine.js         # 遊戲狀態、計時、戰鬥、組裝與章節流程
│   ├── App.vue                # Vue 遊戲狀態、輸入與主迴圈
│   ├── components/            # HUD、戰場、工坊、算子庫與 overlay 元件
│   ├── ui/                    # 共用格式化與圖示資料
│   ├── styles/                # 分區樣式、響應式配置與動效
│   └── main.js                # Vue 應用程式入口
├── tests/                     # Node 內建 test runner 的領域與引擎測試
├── docs/design/               # 採用的 PC 桌面視覺概念稿
├── devlog/                    # 重要功能與驗證紀錄
├── package.json
└── vite.config.js
```

數學領域、純函式關卡生成器、狀態引擎與 Vue 呈現層彼此分離，因此公式轉換、500-seed 不變量與戰鬥規則都可直接在 Node 中測試。關卡 RNG 與工坊／積分 RNG 分流，玩家操作順序不會改變同 seed 的敵人安排。
