# 微分防線

「微分防線」是一款以微積分為戰鬥規則的 PC 網頁塔防遊戲。敵人不是用固定血量表示，而是一條會持續向「證明核心」前進的函數；玩家要部署微分、積分、極限等算子，在敵人抵達基地前把函數化成 `0`。

遊戲採 PC 桌面設計，適合使用滑鼠搭配鍵盤遊玩；較窄的桌面視窗會避免內容溢出，但目前沒有另外設計手機介面。所有內容都在瀏覽器本機執行，沒有後端服務或帳號系統。

## 執行方式

需求：Node.js 18 與 npm。專案固定使用 Vite 6.4.3，並以原生 ES modules 實作，不需要 React 或其他執行期框架。

```bash
npm install
npm run dev
```

開發伺服器預設位於 <http://127.0.0.1:5173>。

執行數學核心與遊戲引擎測試：

```bash
npm test
```

建立正式版並在本機預覽：

```bash
npm run build
npm run preview
```

預覽伺服器預設位於 <http://127.0.0.1:4173>；正式版輸出至 `dist/`。

## 核心玩法

戰場有五條路。玩家花費算力 `Σ`，把砲台放在每路左側五個可部署格；函數敵人由右向左前進，會先攻擊擋路砲台，突破後則攻擊證明核心。每五秒會補充算力，消去敵人也會取得獎勵。

敵人的式子歸零才算被消滅。傷害取目前式子所有項之「係數絕對值總和」，攻擊結算時向上取整且至少為 1。例如 `x⁵` 遭到微分砲連續命中時：

```text
x⁵ → 5x⁴ → 20x³ → 60x² → 120x → 120 → 0
```

因此它要被微分六次才會死亡；常數 `120` 仍不是零，若此時攻擊，能造成 120 傷害。這也代表算子不一定只會削弱敵人：錯誤的微分、平移或極限可能先放大係數，甚至讓敵人暴走。

遊戲共有五波，逐步加入多項式、含常數項、雙變數與指數函數。可用算子如下：

| 按鍵 | 算子 | 效果 |
| --- | --- | --- |
| `1` | `D` 微分砲 | 對同一路目標持續施作 `d/dx`。 |
| `2` | `P(x)−k` 參數平移砲 | 裝入工坊算出的常數後，持續減去該常數。 |
| `3` | `D²` 高階砲 | 每次命中連做兩次微分。 |
| `4` | 定積分塔 | 依序裝入下界與上界，將目標轉為指定區間的定積分。 |
| `5` | `∫ + C` 不定積分 | 對單一敵人積分，並從 `−10、−5、0、5、10` 隨機抽取積分常數。 |
| `6` | `x ↦ −x` 輸入反射 | 對單一敵人替換輸入，例如把 `eˣ` 變成 `e⁻ˣ`。 |
| `7` | `lim x→∞` 無窮極限 | 有限結果會取代原式；若極限發散，敵人六秒內移速變為 1.5 倍、傷害變為 2 倍。 |
| `8` | `∂/∂x` 全場偏微分 | 全場同時對 `x` 偏微分一次，每波限用一次，施放前會顯示結果預覽。 |

部分算子會隨波次解鎖。砲台只會攻擊同一路、位於自己右側且最接近的敵人；點擊已部署砲台可以停火或恢復運算，方便避開不利的中間式。

## 公式工坊：任選公式與 k

工坊有兩條會隨時間補充的佇列：公式與「上帝常數 `k`」。不必只能使用隊首；可以直接點選任意一張公式卡與任意一個 `k`，畫面會即時預覽組合結果。例如選取 `2k` 與 `k = 7`，便會得到常數 `14`。

操作流程：

1. 在公式佇列點選任意公式，例如 `k + 10`、`2k` 或 `k² − 5`。
2. 在常數佇列點選任意 `k`。
3. 確認預覽後按「組裝此常數」；被選的公式與 `k` 會各消耗一張。
4. 點擊有空槽的 `P(x)−k` 砲台，把常數裝成參數；定積分塔則需依序組裝並裝入下界、上界。

兩條佇列容量皆為十張；公式約每六秒補一張，`k` 約每 7.5 秒補一張。佇列滿時會暫停補充，因此主動整理材料也是策略的一部分。

## 丟棄公式、k 與砲台

公式卡、`k` 卡和場上的砲台都能拖曳。把不需要的項目拖到工坊下方的垃圾桶即可丟棄；拆除砲台不會退還算力。丟棄佇列中的卡片能騰出容量，讓計時器繼續補充新選項。

鍵盤玩家可以先用 `Tab` 聚焦公式、`k` 或砲台，再按 `Delete` 執行相同操作。

## 鍵盤操作

| 按鍵 | 操作 |
| --- | --- |
| `1`～`8` | 選擇對應算子。 |
| `Esc` | 取消目前的砲台放置、單體目標或確認視窗。 |
| `Space` | 暫停或繼續演算。 |
| `Tab` / `Shift + Tab` | 在可操作元件間向前／向後移動焦點。 |
| `Enter` | 啟用目前聚焦的按鈕、格子、敵人或砲台。 |
| `Delete` | 丟棄目前聚焦的公式卡、`k` 卡或砲台。 |

切換到其他瀏覽器分頁時，進行中的戰鬥也會自動暫停。

## 專案架構

```text
.
├── index.html                 # Vite 入口與頁面 metadata
├── public/assets/             # 戰場、砲台、敵人與算子圖像
├── src/
│   ├── domain/expression.js   # 式子正規化、微積分、極限、傷害計算
│   ├── game/content.js        # 棋盤、算子、敵人、波次與工坊卡片資料
│   ├── game/engine.js         # 遊戲狀態、計時、戰鬥、組裝與勝敗流程
│   ├── ui/                    # DOM 畫面、格式化與內嵌圖示
│   ├── styles/                # 分區樣式、響應式配置與動效
│   └── main.js                # 輸入綁定、音效與 animation frame 主迴圈
├── tests/                     # Node 內建 test runner 的領域與引擎測試
├── docs/design/               # 採用的 PC 桌面視覺概念稿
├── devlog/                    # 重要功能與驗證紀錄
├── package.json
└── vite.config.js
```

數學領域層與 DOM 呈現層刻意分離，因此函數轉換和戰鬥規則可以直接在 Node 中測試。`src/game/content.js` 則集中管理可調整的波次、費用、冷卻與卡片內容，避免把關卡資料散落在介面程式裡。
