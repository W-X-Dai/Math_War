# 微分防線

「微分防線」是一款以微積分為戰鬥規則的 PC 網頁塔防遊戲。敵人不是用固定血量表示，而是一條會持續向「證明核心」前進的函數；玩家要部署微分、積分、極限等算子，在敵人抵達基地前把函數化成 `0`。

遊戲採 PC 桌面設計，適合使用滑鼠搭配鍵盤遊玩；較窄的桌面視窗會避免內容溢出，但目前沒有另外設計手機介面。所有內容都在瀏覽器本機執行，沒有後端服務或帳號系統。

## 執行方式

需求：Node.js 18 與 npm。專案使用 Vue 3.5.40、Vite 6.4.3 與原生 ES modules；套件版本已精確鎖定，以維持目前 Node 18 開發環境的相容性。

```bash
npm install
npm run dev
```

開發伺服器預設位於 <http://127.0.0.1:5173/>。

開發模式已安裝 Vue DevTools。可按 `Alt + Shift + D` 切換頁內工具列，或開啟 <http://127.0.0.1:5173/__devtools__/> 使用獨立介面；正式版建置不會帶入 DevTools。

執行數學核心與遊戲引擎測試：

```bash
npm test
```

建立正式版並在本機預覽：

```bash
npm run build
npm run preview
```

預覽伺服器預設位於 <http://127.0.0.1:4173/>；正式版輸出至 `dist/`。建置檔使用相對資源路徑，因此既可用 `npm run preview`，也可讓 Live Server 從任意父目錄開啟 `dist/index.html`，不會再因網站掛載路徑不同而找不到 CSS 或 JavaScript。

## 開發參數

遊戲可調參數集中在 [`src/config/`](src/config/README.md)，開發時可從 `src/config/index.js` 一次查看完整入口：

| 檔案 | 內容 |
| --- | --- |
| `content.js` | 章節、棋盤、敵人、軍械、queue 與工坊卡片。 |
| `gameplay.js` | 初始狀態、經濟、整備、戰鬥、幾何、計時與模擬步長。 |
| `generation.js` | 程序公式、變異、出怪、報酬、危險度與無限章成長。 |
| `presentation.js` | 音效、戰場呈現，以及敵人公式卡的尺寸、字級、響應式 profiles 與群聚錯位。 |
| `tutorial.js` | 敵人介紹、固定教學波、出場安排、起始資源與預置塔。 |

設定物件在載入後會遞迴凍結，避免執行期間被意外改寫。數學正規化精度、RNG hash 與浮點 epsilon 屬於演算法相容性邊界，仍留在各自實作檔而不作為平衡參數。修改設定後請執行 `npm test`；生成器參數若改變 seeded 關卡內容，也要同步更新 golden test 與開發紀錄。

## GitHub Pages 部署

專案透過 `.github/workflows/deploy-pages.yml` 在每次推送 `main` 時執行 `npm ci`、建立正式版並將 `dist/` 上傳至 GitHub Pages。首次使用時，在 repository 的 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**；不需也無法在 branch 模式中指定 `/dist`。

正式版使用可攜式相對路徑，部署到 <https://w-x-dai.github.io/Math_War/>、repository 更名、根網域或自訂網域時都不需要再修改 Vite `base`。

## 核心玩法

遊戲採解鎖式選關：第一關預設開放，完成「辨識、壓力、混合」三段後解鎖下一關；六關全數通過後，才會開放沒有勝利終點的「無限證明」。關卡進度會保存在目前網站來源的瀏覽器 localStorage；也可從選關頁下載版本化 JSON 備份，之後上傳同一檔案載入，或確認後清除進度。載入前會驗證檔案類型、版本與關卡順序，無效檔案不會覆蓋目前進度。進行中的戰鬥、seed、成績與教學略過選擇不會保存到瀏覽器或 JSON。

六關依序是「基礎防線、階乘危機、漸近突破、組合推導、週期防線、指數交鋒」。每次從選關頁進入關卡都會產生新 seed，並依該關固定設定重置基地、算力、三條 queue、常數庫、砲台及統計；同 seed、同關卡可完整重現敵人、路線及隨機補給。失敗結算可選擇重試原題、換一個 seed 或返回選關。

地圖會隨關卡由 `4×7` 擴張至 `6×12`，無限模式則為 `7×12`，約六成欄位可部署砲台。同一有限關的壓力段與混合段會延續正式資源，換關或重玩則建立獨立的新局；無限模式使用完整軍械的固定起始配置，之後在輪次之間延續防線與資源。

每章分成三段：「辨識、壓力、混合」。辨識段沿用固定教學波，先介紹本章唯一的新觀念，提供固定軍械與不可回收的示範塔，而且不疊加變異；壓力段讓同類敵人以兩至三隻小隊檢驗處理效率；混合段在不同路加入已學過的敵人，要求安排塔序與分路反制。三段之間都回到整備畫面。

辨識段是獨立沙盒：進入時暫時保存該關正式配置的基地生命、累計資料、RNG、算力、queues、常數庫與所有砲台；失敗只重試教學，通過後完整還原保存內容再進入壓力段。選關詳情可勾選只對本次生效的「跳過本關教學」，直接從壓力段開始；無限模式不插入教學波。

有限段有 30 秒整備；每章只有壓力段可把剩餘整秒換成每秒 `Σ5`、最多 `Σ150` 的一次性提早開始獎勵，混合段不重複發放。無限第 `r` 輪為 `max(10, 32−2r)` 秒。整備摘要會揭露各路主要函數族、次方或頻率／成長率範圍及可能變異，但不會洩漏確切公式、係數或出場時間。

未略過教學時，畫面會先逐張介紹該關的新敵人，再介紹剛解鎖的軍械、部署方式與適用函數。閱讀介紹期間，整備倒數與三條 queue 都會暫停，讀完才開始辨識段。

戰鬥中每五秒會補充算力，消去敵人也會取得獎勵。敵人由右向左前進，會持續攻擊擋路砲台；抵達證明核心時只依當下係數造成一次傷害，隨即離場且不提供消去獎勵。暫停或切換瀏覽器分頁時，戰鬥、整備與補牌計時都會停住。

敵人直接以自己的式子作為外觀，不再另外覆蓋角色圖。本體式歸零才算被消滅；傷害取本體式所有項之「係數絕對值總和」，攻擊結算時向上取整且至少為 1。敵人身上不會提示還需要幾次微分，玩家必須自行判斷；同一路的敵式太靠近時會做小幅錯位，但模擬座標不會改變。例如 `x⁵` 遭到微分砲連續命中時：

```text
x⁵ → 5x⁴ → 20x³ → 60x² → 120x → 120 → 0
```

因此它要被微分六次才會死亡；常數 `120` 仍不是零，若此時攻擊，能造成 120 傷害。這也代表算子不一定只會削弱敵人：錯誤的微分、平移或極限可能先放大係數，甚至讓敵人暴走。

函數敵人包含整數正負次方、雙變數、`aeᵇˣ`、`a sin(bx)`、`a cos(bx)` 與 `axᵖ ln|x|`。可取得的軍械如下：

| 軍械 | 效果 |
| --- | --- |
| `D` 微分砲 | 對同一路目標持續施作 `d/dx`。 |
| `P(x)−[ ]` 參數平移捲軸 | 刻寫工坊常數後，對任意一隻目標減去該常數。 |
| `D²` 高階砲 | 每次命中連做兩次微分。 |
| 定積分捲軸 | 依序刻寫下界與上界，把任意一隻目標化成定積分常數；跨越 `x=0` 奇點時不會施放。 |
| `f([ ])` 代入捲軸 | 只把敵式中的 `x` 代入 `k` 並保留自由變數 `y`；若 `k` 是根可直接歸零。 |
| `xD＋[ ]I` Euler 捲軸 | 刻寫 `k=n` 後可對任意路線的單一目標消去 `ax⁻ⁿ`。 |
| `D²＋[ ]I` 共振捲軸 | 以 `b²` 消去一隻三角式，或以 `−b²` 消去一隻 `aeᵇˣ`。 |
| `∫ + C` 不定積分 | 單體一次性武器，積分常數從 `−10、−5、0、5、10` 隨機抽取。 |
| `x ↦ −x` 輸入反射 | 單體一次性武器，可把成長指數轉成衰減指數。 |
| `lim x→∞` 無窮極限 | 負次方會歸零；三角式極限不存在、其他式若發散則會讓敵人暴走。 |
| `∂/∂x` 全場偏微分 | 昂貴的全場一次性武器，每輪限用一次，施放前會預覽目前最外層式子的結果。 |

每次成功攻擊都會以實際施作的算子作為公式彈頭：只有 `D` 與 `D²` 砲台沿路線射出水平子彈；參數捲軸與其他單體武器都由上方落向手動選定的敵人，全場偏微分則對每隻存活敵人各落下一枚 `∂/∂x`。公式中的正負號、`π`、上下界與捲軸參數都會反映當次攻擊。彈頭飛行期間不會預先改寫敵式；只有真正命中時，才會依敵人當下最外層的式子結算。水平彈頭的原目標若先被消去，會繼續命中同路下一隻敵人；由上方落下的捲軸仍鎖定施放時的目標，目標提前消失時只會落空。捲軸通過施放前檢查並發射時就會消耗；發射後落空不退還。

軍械不是無限購買：容量八張的軍械 queue 每八秒從已解鎖軍械中依本段需求加權補一張隨機牌。每個正式段開始時還會一次注入足以處理每隻敵人本體、護盾與分裂子代的保障軍械、公式及 `k`；保障補給可暫時超出 queue 容量，隨機補牌則等 queue 回到容量以下才繼續。刻寫捲軸會消耗已組裝常數；成功放塔或捲軸發射時才會消耗軍械牌與算力。取消、目標無效、施放前運算無效或算力不足時不消耗已刻寫捲軸。

敵人可能帶有「快進」、「等式護盾」或「分裂」變異。快進提升速度與獎勵；等式護盾會把本體式的獨立複本做成一張卡，直接覆蓋在本體上。所有算子都會先改寫這張護盾式，只有把它化成 `0` 才會揭露本體，而且同一發攻擊不會穿透到本體；破盾本身不算消去，也不提供獎勵。分裂敵人歸零後會拆成兩隻不可再次分裂、且仍能由原路防線處理的子敵人。有限章每隻敵人最多一種變異；無限第十一輪才開始容許兩種變異。

## 關卡策略與難度（0.10.0）

六章各自只新增一個主要判斷，並把壓力依「同路小隊 → 雙路同步 → 快慢交錯 → 單一變異 → 速度與公式複雜度」逐步提高：

- 第 1 章「基礎防線」：常數、一次式、二次式；學會 D 的部署位置與最後一次消去。
- 第 2 章「階乘危機」：三至五次單項式，混合段穿插低階快敵；D 清雜兵，D² 壓高階。
- 第 3 章「漸近突破」：首次出現 D 永遠無法消去的單項分式；判斷負次方後對單一目標施放 Euler 捲軸。
- 第 4 章「組合推導」：對數使用 `f(1)`，分式使用 Euler 捲軸，高階式與多變數交給 D²。
- 第 5 章「週期防線」：普通三角敵人只有單一頻率，後段可出現同頻 sin＋cos；共振捲軸要刻寫正確的 `b²`。
- 第 6 章「指數交鋒」：每隻指數敵人只有一個成長率；共振參數為 `−b²`，衰減式可用極限，成長式不可直接取極限。

D 維持 Σ100／1.75 秒；D² 為 Σ150／2.2 秒，一發降兩階，兩者都是會持續射擊且能擋路的通用砲台。參數捲軸不占塔位，但每張只能對一隻敵人施放一次，因此價格降為 Σ25～Σ50；玩家用較低的單次成本換取跨路線選目標的彈性。

普通敵人最多只要求一種專用反制或兩步塔序；普通分式為單項、三角式保持同頻、指數保持單一成長率，同一路在一次小波中不切換反制。有限章不疊雙變異，護盾不會再同時快進。混頻只在無限模式的已預告精英出現，整備時會提供完整參數解法。無限模式的敵數、同時路數、變異、速度、項數與次方上限採逐輪單軸解鎖或輪替增加。

有限關卡的 seeded 內容已全面更新；無限模式也改用上述單軸成長順序。測試以 500 個 seed 驗證數學可解性、逐路反制穩定、公式複雜度、變異限制與精確保障材料。這些是自動化基準，組裝負擔、反應時間、失敗原因是否清楚及長期經濟仍需真人實戰調校。

## 公式工坊：任選公式與 k

工坊有兩條會隨時間補充的佇列：公式與「上帝常數 `k`」。不必只能使用隊首；可以直接點選任意一張公式卡與任意一個 `k`，畫面會即時預覽組合結果。例如選取 `2k` 與 `k = 7`，便會得到常數 `14`。

操作流程：

1. 在公式佇列點選任意公式，例如 `k`、`k + 10`、`2k`、`k²` 或 `−k²`。
2. 在常數佇列點選任意 `k`。
3. 確認預覽後按「組裝此常數」；被選的公式與 `k` 會各消耗一張，結果存入最多五格的常數庫。
4. 任選一個已存常數，再點擊軍械 Queue 中相容的空白參數捲軸刻寫；定積分捲軸需依序刻寫下界與上界。刻寫成功才會消耗該常數。
5. 再點一次已刻寫捲軸，對戰場上任意一隻敵人施放；已完成的捲軸不會被新選取的常數意外覆寫。

兩條佇列容量皆為十張；隨機公式約每六秒補一張，隨機 `k` 約每 7.5 秒補一張，且 `k` 可抽到 `π` 與 `−π`。正式段的保障材料會直接加入並以徽章標示；例如需要 `−4` 時會直接提供 `−k²` 與 `k=2`，而不是只增加抽中的機率。queue 位於或高於容量時隨機補牌倒數會停在原位，直到消耗或丟棄出空間。常數庫滿五格時不能再組裝，但不會誤扣材料；未使用的庫存會在同一關的正式段之間或無限輪次之間保留，但不會跨到另一個獨立關卡。

## 丟棄資源與回收砲台

軍械牌、公式卡、`k` 卡與已組裝常數可拖到工坊下方的垃圾桶丟棄，不受 queue 位置限制。砲台不再拖進垃圾桶：把工坊中的回收鏟拖到玩家砲台上，即可回收並取得該塔原價一半的補償算力；回收鏟也能先點擊啟用，再點選要回收的塔。教學預置塔不可回收。

普通點擊砲台不會切換休眠或停火；只有在回收模式中才會執行回收。鍵盤玩家可聚焦玩家砲台後按 `Delete` 執行相同的半價回收。

## 鍵盤操作

| 按鍵 | 操作 |
| --- | --- |
| `1`～`8` | 選擇軍械 queue 對應槽位。 |
| `Esc` | 取消目前的砲台放置、單體目標或確認視窗。 |
| `Space` | 暫停或繼續演算。 |
| `Tab` / `Shift + Tab` | 在可操作元件間向前／向後移動焦點。 |
| `Enter` | 啟用目前聚焦的按鈕、格子、敵人或砲台。 |
| `Delete` | 丟棄目前聚焦的軍械、公式、`k` 卡、已組裝常數；聚焦砲台時則半價回收。 |

切換到其他瀏覽器分頁時，進行中的戰鬥也會自動暫停。

## 專案架構

```text
.
├── index.html                 # Vite 入口與頁面 metadata
├── public/assets/             # 戰場、砲台、敵人與算子圖像
├── src/
│   ├── config/                # 內容、玩法、生成、教學與呈現的集中開發參數
│   ├── composables/           # 選關、單局切換與本機進度協調
│   ├── domain/expression.js   # 式子正規化、微積分、極限、傷害計算
│   ├── game/content.js        # 舊匯入路徑的相容轉接
│   ├── game/level-generator.js # Seeded 有限／無限波次與摘要生成器
│   ├── game/progress.js      # 本機通關紀錄、解鎖規則與版本化儲存
│   ├── game/tutorial-content.js # 固定教學波生成與舊匯入路徑相容介面
│   ├── game/engine.js         # 遊戲狀態、計時、戰鬥、組裝與關卡流程
│   ├── App.vue                # 選關／戰鬥切換、輸入、存檔與主迴圈
│   ├── components/            # HUD、戰場、工坊、算子庫與 overlay 元件
│   ├── ui/                    # 共用格式化與圖示資料
│   ├── styles/                # 分區樣式、響應式配置與動效
│   └── main.js                # Vue 應用程式入口
├── tests/                     # Node 內建 test runner 的領域與引擎測試
├── docs/design/               # 採用的 PC 桌面視覺概念稿
├── devlog/                    # 重要功能與驗證紀錄
├── package.json
└── vite.config.js
```

數學領域、純函式關卡生成器、狀態引擎與 Vue 呈現層彼此分離，因此公式轉換、500-seed 不變量與戰鬥規則都可直接在 Node 中測試。關卡 RNG 與工坊／積分 RNG 分流，玩家操作順序不會改變同 seed 的敵人安排。
